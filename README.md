# EduPro Online Learning Analytics & Predictive Modeling

An end-to-end data analytics and machine learning project for an online learning platform. The project covers data cleaning, exploratory data analysis, business analysis, predictive modeling, feature importance analysis, and an interactive Power BI dashboard.

## 📌 Project Overview

EduPro is an online learning platform containing information about users, courses, teachers, and transactions.

The main goal of this project is to analyze platform performance and build machine learning models for:

- Course Enrollment Prediction
- Course Revenue Prediction
- Revenue Feature Importance Analysis
- Business Performance Analysis
- Interactive Power BI Dashboard

---

## 🎯 Objectives

- Integrate multiple EduPro datasets
- Clean and prepare the data
- Perform Exploratory Data Analysis (EDA)
- Analyze course and transaction performance
- Analyze payment methods and course levels
- Predict course enrollment
- Predict course revenue
- Compare multiple machine learning models
- Identify important revenue drivers
- Build an interactive Power BI dashboard
